文本转语音工具 — 使用教程

这是什么？

文本转语音（Text-To-Speech，简称 TTS）是一种将文字转换为自然语音朗读的技术。本工具借助浏览器内置的语音合成能力，把输入的中文（或其他语言）文字直接朗读出来，无需联网、不上传服务器。

如何使用

  • 在文本框中输入或粘贴需要朗读的内容；
  • 在「语音」下拉框中选择喜欢的声音（默认优先列出中文语音）；
  • 拖动语速 / 音调 / 音量滑块调整到合适效果；
  • 点击播放开始朗读，播放中可再次点击按钮暂停 / 继续，点击停止结束；
  • 点击下载音频可将当前文本合成为 MP3 文件保存到本地（需联网，调用微软 Edge 在线语音服务，可在「下载音色」中选男女声）。

常见使用场景

  • 听文章 / 听小说：把长文粘贴进来，闭眼听；
  • 校对文稿：朗读能帮人更快发现错别字和语病；
  • 辅助阅读：为视力不便或需要多任务处理的用户提供便利；
  • 语言学习：听标准发音，纠正自己的读法。

为什么读出来是英文口音 / 没有中文？

语音列表由你的操作系统提供。若列表里没有中文语音，请先在系统中安装中文语音包（Windows：「设置 → 时间和语言 → 语音 → 添加语音」选“中文(简体，中国)”；macOS：「系统设置 → 辅助功能 → 语音内容 → 系统声音」下载中文）。安装后刷新本页面即可看到。

数据安全

「播放」功能的所有语音合成均在本地浏览器完成，文字内容不会被发送到任何服务器，可放心处理私密文本。而「下载音频」为获取可保存的文件，会调用微软 Edge 在线语音服务，相应文本会被发送给微软，请勿用于高度敏感内容。
