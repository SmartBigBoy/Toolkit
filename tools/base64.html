什么是 Base64 编码？

Base64 是一种将二进制数据转换为纯文本的编码方式。它用 64 个可打印字符（A-Z、a-z、0-9、+、/）来表示任意数据，常用于在文本协议中嵌入图片、传输加密数据等场景。

Base64 编码 vs Base64 解码

  • 编码（Encode）：把普通文本或二进制数据 → 转成 Base64 字符串。例如 Hello 编码后变成 SGVsbG8=
  • 解码（Decode）：把 Base64 字符串 → 还原为原始数据

常见使用场景

  • 图片转 Base64：把图片编码后直接嵌入 HTML/CSS 中（Data URI），减少 HTTP 请求，适合小图标、Logo 等
  • API 认证：HTTP Basic Auth 的 Authorization: Basic xxxx 头部就是用 Base64 编码的用户名密码
  • 数据传输：在 JSON 中传输二进制数据时，常用 Base64 编码包裹一层
  • 加密数据输出：加密算法输出的二进制结果通常用 Base64 转成可读字符串
  • Email 附件：MIME 协议使用 Base64 编码邮件附件

Base64 的局限性

Base64 编码后的数据比原始数据大约大 33%，不适合压缩场景。如果需要减少体积，应使用压缩算法（如 Gzip），Base64 应仅用于需要文本表示的场合。

数据安全说明

所有编解码操作完全在您的浏览器本地完成，文本和文件不会上传到任何服务器，请放心使用。
