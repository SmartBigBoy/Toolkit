什么是 URL 编码？

URL（网址）只能直接传输 ASCII 字符集中的部分字符。中文字符、空格、特殊符号等都需要转换为 %XX 的格式才能在 URL 中安全传输，这个过程就是 URL 编码（也叫百分号编码）。

例如：你好 编码后变成 %E4%BD%A0%E5%A5%BD，空格 变成 %20。

什么时候需要 URL 编码？

  • GET 请求传参：URL 参数中包含中文或特殊字符时必须编码，否则可能导致乱码或请求失败
  • 前端路由：Vue/React 路由跳转时，动态参数包含特殊字符需要编码
  • 分享链接：分享的网址中包含中文或特殊符号时，浏览器会自动编码
  • API 签名：很多开放平台的接口签名算法要求对参数做 URL 编码

encodeURI vs encodeURIComponent

JavaScript 有两个编码函数，区别很重要：

  • encodeURIComponent()：编码范围更广，会编码 / ? & = # 等 URL 保留字符，适合编码参数值
  • encodeURI()：保留 URL 结构字符，只编码非法字符，适合编码完整 URL

本工具使用的是 encodeURIComponent 级别的完整编码，确保编码后的结果在任何位置都能安全使用。

数据安全说明

所有编解码操作完全在浏览器本地完成，您的数据不会上传到任何服务器。
